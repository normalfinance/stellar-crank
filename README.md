# Normal Stellar Crank

A REST API for manual and off-chain function of Normal's Stellar contracts.

## Tech Stack

**Serverless:** nodejs20.x, Lambda

## Deployment

To deploy this project, simply push a commit to the `develop` or `staging` branch or create a Pull Request on any branch.

Bitbucket will use the `bitbucket-pipelines.yml` file to automatically deploy your changes to the correct environment.

## Environment Variables

To view or manage the environment variables necessary for this project to run, navigate to the Bitbucket repository > Repository settings > Deployments.
